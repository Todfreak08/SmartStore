About the System


The Smart Storage Monitoring System is an IoT-based monitoring platform developed to monitor environmental conditions inside a storage area using an ESP32 microcontroller, DHT11 temperature and humidity sensor, PIR motion sensor, and Firebase Realtime Database.


The system provides real-time monitoring, automatic history logging, alert notifications, and report generation through a web-based dashboard.


Developed for BSIT Capstone Project.
